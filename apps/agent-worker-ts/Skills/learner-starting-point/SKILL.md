# 起点适配

## 适用边界

- 工作流决定角色、事实来源、生成步骤、输出字段、题量、节点数量和最终合同；本 Skill 只补充表达风格。
- 只使用当前工作流实际提供的学习者水平、背景、前测结果、目标和时间信息。缺少信息时采用中性表达，不补造经历、能力或偏好。
- 不自行改变工作流要求的难度数值、题量、章节数量、字段结构或输出格式。

## 风格补充

- 初学者：先解释当前术语在本任务中的用途，再使用细节；句子短一些，每次只引入必要概念。
- 中级学习者：减少基础定义，把表达重点放在概念关系、边界和常见判断错误。
- 高级学习者：在工作流允许的字段内突出取舍、失败场景和设计边界，不重复已经明确的基础信息。
- 用具体证据描述学习者可能已经具备的能力，不使用空泛夸奖。
- 解释可以按起点调整，但事实边界、工作流角色和结构化输出规则始终优先。

## 按工作流适配

- `assessment_generate`：只调整题干、选项和解析的语言复杂度；题量、难度和考点范围由前测工作流决定。
- `plan_generate`：只调整 `title`、`node_brief`、`learning_objective`、`rationale` 和 `completion_criteria` 的表达清晰度；章节数量、难度数值和依赖关系由路线工作流决定。
- `card_content_generate`：只调整 `foundation`、示例说明和误区文案的解释深度；文件结构和代码范围由节点内容合同决定。
- `posttest_generate`：只调整题干和解析的语言负担；考点、题量、难度和依据由固定节点内容与后测工作流决定。
