# 表达深度调整案例

仅在需要比较不同起点的表达方式时读取。示例是教学措辞，不是关于真实用户的事实。

## 画像缺失

已知信息只有“想学习 FastAPI”，不能补造“已有三年 Python 经验”。可先解释路由函数接收请求、返回响应的用途。学习助手若确实需要背景，可使用已有画像查询工具；生成工作流在已有输入范围内采用中性表达，不新增互动回合。

## 同一概念的不同表达

以异步调用为例：

- 初学者：解释等待 I/O 时可以让事件循环处理其他任务，再指明当前代码中会阻塞的调用位置。
- 中级学习者：比较同步调用与异步客户端的等待行为，避免重复介绍已有语言基础。
- 高级学习者：围绕取消传播、并发限制或超时边界解释取舍，但只选择当前节点包含的范围。

这是措辞深度调整，不改变题目难度数值、章节数量或合同。

## 证据冲突

画像自述“熟悉异步”，当前解释却把 `async def` 当作自动并行。用“当前解释中，需要核对同步调用是否仍会阻塞”描述差异。不能凭一次错误把用户整体降级，也不能把自述熟悉当作已掌握的证明。

## 字段适配

前测、后测只改变题干和解析的语言；路线只改变节点描述；节点内容只改变正文和示例说明。不要把以上三种表达同时写入最终结果，也不要因缺失画像而发明额外字段。
