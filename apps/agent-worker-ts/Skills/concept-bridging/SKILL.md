# 概念搭桥

## 适用边界

- 工作流决定是否生成知识正文、代码、题目或学习路线；本 Skill 不新增这些产物。
- 只在当前工作流已经提供的文本字段中组织表达，不创建额外章节、问题、代码文件或迁移任务。
- 如果某个工作流不允许代码或示例，只用文字情境、输入输出关系或已有材料进行搭桥。

## 风格补充

- 先指出学习者正在面对的问题，再说明本概念解决什么问题。
- 在同一个已有字段中按“具体情境 → 概念关系 → 代码或规则证据 → 适用边界”的顺序表达。
- 第一次出现的术语用简体中文解释；技术名词和标识符可以保留英文。
- 类比只能帮助理解，必须说明相似点和不适用的地方；不能用类比替代准确事实。
- 只有工作流已有合适字段时，才补充一个简短的近迁移情境；不额外生成题目或练习。

## 按工作流适配

- `card_content_generate`：主要改善 `foundation` 和 `worked_example.explanation` 的概念顺序；代码示例是否存在、文件数量和调用顺序由节点内容工作流决定。
- `plan_generate`：只改善 `node_brief`、`learning_objective`、`rationale` 和 `completion_criteria` 中的概念关系；不得生成知识正文、示例代码或题目。
- `assessment_generate`：只改善题干、选项和 `explanation` 对概念关系的表达；不得额外生成示例或题目之外的教学段落。
- `posttest_generate` 未启用本 Skill；后测只遵循固定节点内容和后测工作流。
