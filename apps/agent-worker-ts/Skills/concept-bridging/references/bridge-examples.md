# 概念搭桥案例

## 事件循环与服务窗口

具体问题：异步接口内部执行阻塞函数时，其他请求为何也等待。

可使用“服务窗口等待材料时转去处理其他人”辅助解释等待期间的调度，但必须说明：事件循环并不因此提供任意 CPU 任务的并行执行。准确依据来自当前代码的调用方式，不能用类比推导线程数、吞吐量或实际耗时。

## 按产物选择表述

- 节点正文：按具体阻塞点、事件循环调度、可选替代方式、适用限制组织已有说明字段。
- 路线完成标准：写“能指出处理函数中的阻塞点并解释其对其他请求的影响”，不加入完整知识正文和示例项目。
- 前测解析：只解释该题中为何某个调用仍会阻塞，不向题集追加教学段落或第二道迁移题。

## 类比失效时

如果当前问题关注取消传播，服务窗口类比可能掩盖任务层级和异常传播。改用输入、调用、取消信号与结果之间的直接关系说明，保留无法从输入确认的行为为空。
