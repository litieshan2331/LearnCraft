# Spec Delta

## Purpose

为学习助手提供与会话短期状态分离的长期记忆能力，通过可替换的 mem0 适配器提交完整会话对话并由 mem0 提取、检索和删除学习记忆，同时保证用户隔离、幂等和故障可控。本能力在本次变更中延期，不接入 Worker 运行路径，以下合同作为后续 mem0 独立变更的设计基线。

## ADDED Requirements

### Requirement: 长期记忆通过可替换适配器管理

学习助手 SHALL 通过注入的长期记忆端口调用 mem0；工作流不得直接依赖 mem0 SDK、HTTP 地址或具体部署形态。

#### Scenario: 切换 mem0 部署形态
- **WHEN** 将 mem0 从自托管服务切换为 Mem0 Platform 或测试替身
- **THEN** 仅替换基础设施装配和配置，工作流的 State、Agent 工具和公开会话契约保持不变

### Requirement: 记忆输入边界由服务端控制

系统 SHALL 将当前学习助手会话的完整对话提交给 mem0，由 mem0 提取长期记忆；服务端 SHALL 决定用户命名空间和会话来源，模型输出不得直接决定用户身份、所属会话或写入目标。

#### Scenario: 提交完整会话
- **WHEN** 当前学习助手会话产生新的对话消息
- **THEN** 系统将该会话完整对话提交给当前用户命名空间下的 mem0，由 mem0 负责提取、合并或更新记忆

#### Scenario: 模型不能选择记忆归属
- **WHEN** 模型输出或工具参数包含用户 ID、会话 ID 或记忆命名空间
- **THEN** 服务端忽略这些值，仅使用已认证运行绑定的用户和会话标识提交完整对话

### Requirement: 长期记忆按用户隔离并支持受控检索

每次 mem0 操作 SHALL 使用服务端绑定的用户命名空间，并将检索结果限制在当前用户和允许的学习助手场景；长期记忆原文不得直接进入公开会话响应。

#### Scenario: 跨用户访问
- **WHEN** 请求使用与运行连接不匹配的用户标识检索或删除记忆
- **THEN** 操作被拒绝且不向调用方返回其他用户的记忆内容

#### Scenario: 主 Agent 使用历史记忆
- **WHEN** 学习助手需要用户的长期学习背景
- **THEN** 工作流通过受控端口取得必要摘要并放入 LangGraph State，主 Agent 只获得当前任务所需内容

### Requirement: 记忆操作幂等且可审计

记忆添加、更新和删除 SHALL 使用由操作 ID、用户 ID 和稳定内容标识组成的幂等键；重复投递不得产生重复记忆，并 SHALL 记录不含密钥和完整记忆原文的操作结果。

#### Scenario: 运行重试
- **WHEN** 同一运行在 mem0 请求完成后、Checkpoint 保存前重试
- **THEN** 重复调用不会创建重复记忆，结果可由幂等键复用或安全确认

#### Scenario: 删除用户记忆
- **WHEN** 收到已授权的用户记忆删除请求
- **THEN** 适配器按用户命名空间和稳定记忆标识执行删除，并写入可追踪的成功或失败观测事件

### Requirement: mem0 故障不破坏当前会话

mem0 超时、限流、不可用或配置错误 SHALL 按配置执行有限重试和降级；长期记忆失败不得导致已经生成的当前轮会话回复被重复生成或公开失败，除非该运行明确要求强一致记忆写入。

#### Scenario: 写入超时
- **WHEN** mem0 写入在限定时间内未完成
- **THEN** 记录可重试的记忆操作失败，保留当前回复和 Checkpoint，并在后续补偿或重试中继续处理

#### Scenario: 检索不可用
- **WHEN** mem0 检索失败且当前请求不要求长期记忆才能回答
- **THEN** 使用空的长期记忆摘要继续当前对话，并记录降级原因
