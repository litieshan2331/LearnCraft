# 学习者动态舒适界面设计方案

> 文档状态：待评审  
> 创建日期：2026-08-30  
> 适用范围：LearnCraft 学习者端前端视觉、布局与动效表现。  
> 非目标：本方案不改变课程、任务、进度、路由、权限、接口或其他前端业务逻辑。

## 1. 设计目标

当前界面需要从“静态页面直接切换”升级为“有节奏地呈现学习状态”，同时避免动画和强游戏化给学习者带来压力。

- 进入页面时建立探索感和欢迎感，而非突然弹出下一层界面。
- 让学习者始终清楚：我学到哪里、下一步做什么、完成后获得了什么。
- 用柔和色彩、留白和克制动效降低长时间学习的视觉疲劳。
- 保持现有产品逻辑不变；动效只用于解释页面状态、层级与反馈。

## 2. 推荐风格

建议采用 **“轻未来探索感 × 安静学习空间”** 的混合风格：

- 以 DeepSeek Harness 的首屏层次和探索入口建立第一印象。
- 以 Headspace 的低饱和、圆润、有呼吸感的视觉氛围降低紧张感。
- 以 Khan Academy 的“继续学习优先”和清晰学习路径减少选择负担。
- 以 Brilliant 的可视化课程卡片提升知识探索欲。

不建议直接复制任何参考网站的品牌资产、字体、插画、图标或配色；只借鉴其界面方法。

## 3. 首页信息架构

首页遵循“一个主行动、两组辅助信息、低压力探索”的优先级。

```text
┌──────────────┬────────────────────────────────────────────┐
│ 学习          │  晚上好，Alex                     学习状态   │
│ 课程          │  今天从上次停下的地方继续吧                  │
│ 复习          │  ┌──────────────────────────────────────┐  │
│ 成就          │  │ 继续学习：Python 第 3 章                │  │
│              │  │ 62%  ───────────────────────●          │  │
│              │  │ [继续学习]                              │  │
│              │  └──────────────────────────────────────┘  │
│              │  学习路径：基础 → 当前章节 → 项目实践       │
│              │  进行中课程                 今日小目标       │
│              │  推荐复习                   最近笔记         │
└──────────────┴────────────────────────────────────────────┘
```

### 3.1 首屏区域

- 顶部使用“问候语 + 一句低压力引导”，例如“今天从上次停下的地方继续吧”。
- 中央只突出一张“继续学习”主卡，展示课程名、当前章节、完成进度、预计时长和唯一主按钮。
- 主卡之后再展示学习路径、进行中课程、推荐复习和最近笔记，避免首屏堆放大量平级卡片。
- 页面背景可采用很浅的雾蓝渐变与缓慢漂浮的抽象知识节点，不使用大面积粒子、扫描线或强视差。

### 3.2 课程页

- 课程头部保留明确的课程名、完成比例和“下一步”信息。
- 章节使用纵向学习路径或分段进度条展示；当前章节以主色高亮，其余章节使用低对比度中性色。
- 每个章节卡只放置一个主操作，次级内容折叠或放在卡片底部，避免学生每次都面对多个选择。
- 视频、阅读、练习等内容类型用统一的小图标和标签区分，不以大面积色块区分。

### 3.3 学习完成与复习区域

- 完成后显示简短肯定反馈，例如“完成了，下一步可以巩固这个知识点”。
- 成就与连续学习仅作为辅助信息，不抢占“继续学习”主卡的位置。
- 复习入口表述应温和，例如“花 5 分钟回顾一下”，避免使用焦虑式文案或倒计时催促。

## 4. 动效规范

动效的职责是说明“页面已准备好”“我正在进入什么内容”“这一步已完成”，而不是持续吸引注意力。

| 场景 | 表现建议 | 时长与限制 |
| --- | --- | --- |
| 首次进入学习首页 | 背景先出现，问候语和主卡轻微上移淡入，辅助卡依次出现 | 总时长 500–700ms；相邻元素间隔 80–120ms |
| 页面切换 | 原页面轻淡出，新页面轻淡入；课程卡可保持位置连续感 | 220–280ms；不阻塞点击或数据加载 |
| 卡片悬停 | 上浮 2–4px、阴影略增强、边框或图标高亮 | 120–180ms；不缩放整张卡片 |
| 进度更新 | 进度条平滑填充，完成点短暂亮起 | 300–450ms；仅在真实进度变化时触发 |
| 完成反馈 | 勾选图标或轻量粒子一次性出现 | 450–600ms；不循环、不遮挡下一步 |
| 加载状态 | 骨架屏与内容淡入衔接 | 避免空白页、旋转大图标和长时间跳动 |

### 4.1 禁止项

- 不自动打开新的界面或模态框。
- 不使用持续闪烁、快速缩放、无限循环跳动的装饰。
- 不使用横向大幅视差、滚动触发的大面积漂移。
- 不让动效延迟页面可用性；用户点击后应立即获得操作反馈。

### 4.2 无障碍要求

应适配系统的“减少动态效果”偏好：在该模式下，移除非必要位移、缩放和装饰性循环动效，仅保留简短淡入或静态状态变化。W3C 的 WCAG 2.3.3 明确建议用户能够关闭非必要的交互动效，以避免分心、眩晕或不适。

参考：[W3C — Understanding Success Criterion 2.3.3: Animation from Interactions](https://www.w3.org/WAI/WCAG21/Understanding/animation-from-interactions)

## 5. 视觉系统建议

### 5.1 色彩

| 用途 | 建议色值 | 使用原则 |
| --- | --- | --- |
| 页面底色 | `#F7F8F5`、`#EEF5F5` | 温和、低刺激，不使用纯白大面积铺满 |
| 主色 | `#2D7C83` | 用于主按钮、当前路径、关键状态 |
| 强调色 | `#F2B866` | 仅用于进度、提醒和完成反馈 |
| 正文 | `#1F2D33` | 保证阅读对比度 |
| 次级文字 | `#617176` | 用于说明、时间和辅助信息 |
| 卡片 | `#FFFFFF` 或半透明白 | 配合极轻阴影和柔和边框 |

### 5.2 排版与组件

- 中文字体优先使用系统无衬线字体；标题强调层级，正文保证长时间阅读舒适。
- 正文建议不小于 16px，行高建议不小于 1.6。
- 卡片圆角建议 16–20px；统一圆角、阴影、间距，避免每类卡片都是不同语言。
- 图标以线性、圆角风格为主；同一页面不要混用拟物、填充和 3D 图标。
- 主按钮仅使用一种高强调样式，次按钮使用描边或文字样式，避免出现多个“最重要”的动作。

## 6. 在线参考与对应改动

| 参考网站 | 可借鉴的界面方法 | LearnCraft 的对应改动 |
| --- | --- | --- |
| [DeepSeek Harness](https://www.deepseek.com/harness/en/) | 用强主题、分层信息和明确入口建立探索感。该网站当前提供多个模式及演示入口。 | 首页使用“今天想学习什么”或“从上次继续”作为核心入口，并通过分层淡入建立场景感；不采用其深色开发者工具视觉。 |
| [Brilliant](https://brilliant.org/) | 将学习描述为可视化、可互动的概念探索，并使用阶段进度激励持续学习。 | 把静态课程列表升级为带主题插画、章节进度、预计时长的课程卡；每次仅突出一个推荐学习动作。 |
| [Duolingo 动效设计案例](https://blog.duolingo.com/streak-milestone-design-animation/) | 用里程碑动效庆祝关键学习成果，强调动效节奏和奖励感。 | 仅在连续学习、章节完成、掌握新技能时显示一次简短庆祝；日常操作保持安静。 |
| [Khan Academy 学习者首页说明](https://support.khanacademy.org/hc/en-us/articles/360030629852-What-is-my-Learner-Home-page-and-what-can-I-do-there) | 登录后优先展示最活跃或最适合开始的学习事项，并聚合课程、任务与进度。 | 固定“继续学习”为首页主卡；课程、复习、笔记和成就放在后续区块，按学习优先级组织。 |
| [Headspace](https://www.headspace.com/) | 使用圆润形状、低饱和色与按当前需求分类的内容，营造可停留的舒适感。 | 应用于背景、卡片轮廓与轻量装饰；加入“专注 10 分钟”“轻松复习”等低压力入口。 |
| [Codecademy](https://www.codecademy.com/) | 用逐步引导、互动课程和可见进度让学习过程可预期。 | 课程详情改为“章节路径 + 当前步骤 + 下一步”信息结构，让学习者随时理解自己的位置。 |

## 7. 评审清单

- 首屏包括网页介绍以及一个最清晰的主学习行动
- 用户能在 3 秒内看懂“我学到哪里、下一步做什么”
- 动效只用于进入、切换、反馈，而没有抢夺阅读注意力
- 不存在自动弹窗、自动跳页或不可关闭的循环动效
- 色彩、文字和按钮保持足够对比度与可读性
- 系统默认无开启动态效果按钮，直接设计 UI 即可
- 没有因视觉改版改变任何既有业务逻辑

## 8. 后续设计输出建议

本方案通过评审后，再依据实际首页、课程页和练习页截图，输出以下不涉及逻辑变更的交付物：

1. 页面级高保真视觉稿。
2. 组件清单：导航、学习主卡、课程卡、进度组件、反馈组件、空状态和骨架屏。
3. 页面进入、卡片交互、完成反馈、加载状态的动效标注。
4. 浅色与深色模式的视觉规则（如项目当前已支持或计划支持）。
